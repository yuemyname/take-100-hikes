# 100PEAKS Visual References

UI implementation agents must inspect the visual reference assets in this directory before implementing screens.

## Expected assets

1. `visual-reference-01.jpg`
   - Original user-provided reference.
   - Use for saturated primary-color energy, fuzzy mascot direction, playful/naive character personality, hand-made imperfections and sticker/doodle mood.

2. `visual-reference-02.jpg`
   - Original user-provided reference.
   - Use for photo + illustration collage, editorial poster composition, mountain/outdoor imagery and playful typography mood.

3. `100peaks-ui-concept.png`
   - Generated 100PEAKS concept board.
   - This is the closest visual target for the actual product UI: cream base, strong black hierarchy, saturated accent colors, mountain photography, mascot overlays, collection progress, mountain detail, mutual-friend certification list, GPS/photo verification, and shared certification.

## Priority

`100PEAKS_MASTER_SPEC.md` is always the implementation source of truth.

The images define visual intent and target feel. They do not override product behavior, navigation, database rules, accessibility, or shared-certification logic in the master spec.

## Copyright / originality rule

The original references are inspiration only. Do not copy Netflix branding, logos, program title graphics, proprietary typography, or exact characters. 100PEAKS must use an original wordmark and original mountain mascots.

## If image files are missing

Do not guess their contents. Follow the visual description in `100PEAKS_MASTER_SPEC.md` and report that the binary reference assets need to be added.
