# BAC 명산100 산 정체성 감사 기록

## 감사 범위

- 확인일: 2026-09-08 (Asia/Seoul)
- 대상: `docs/data/bac100-candidates.csv`의 100개 산 이름, 인증지명, 지역, 고도, 산림청 대응 관계
- 제외: GPS 좌표와 인증 반경. 이 감사에서는 좌표를 수집·추정·활성화하지 않는다.

## 사용한 출처

1. BAC 공식 명산100 프로그램 페이지
   - https://bac.blackyak.com/BAC/ChallengeProgram/114
2. 위 페이지가 사용하는 BAC 공식 공개 목록 응답
   - https://bac.blackyak.com/BAC/ChallengeProgram/getlist.asp?program_id=114
3. 천성산의 현재 운영 상태를 확인한 BAC 공식 명산100 버스 페이지
   - https://bac.blackyak.com/BAC/bus/
   - https://bac.blackyak.com/BAC/bus/Registration/Individual/?bacbus_sc_id=142
4. 산림청 공식 100대 명산 목록
   - https://www.forest.go.kr/kfsweb/kfi/kfs/foreston/main/contents/FmmntSrch/selectFmmntSrchList.do?mn=AR02_02_05_01&mntIndex=1&mntUnit=100&orgId=&searchCnd=&searchMnt=
5. BAC 공식 앱 설명
   - https://play.google.com/store/apps/details?id=kr.co.mountainbook.android.alpineclub&hl=ko

BAC가 직접 운영하는 1–3번을 BAC 이름과 인증지명의 1차 출처로 사용했다. 산림청 대응 관계는 4번의 공식 100개 목록과 지역·대표봉을 함께 비교했다. 앱 설명은 BAC 앱이 프로그램별 인증지 위치와 현장 GPS를 사용한다는 운영 원칙 확인에만 사용했다.

## 감사 결과

- 후보 행: 100개
- 산림청 공식 목록과 같은 산 정체성을 재사용하는 행: 79개
- BAC에만 있는 별도 도전 대상: 21개
- `coordinate_status`: 100개 모두 `pending`
- 이번 감사로 추가하거나 `verified`로 바꾼 GPS 좌표: 0개

BAC 공식 공개 목록 응답은 확인일 현재 99개 행을 반환했다. 빠진 행은 `천성산`이다. 같은 시점의 BAC 공식 명산100 버스가 천성산을 2026-09-12 일정으로 운영하며 인증지를 `원효봉`, 고도를 `922m`로 명시하므로 CSV의 오래된 `비로봉 855m`를 이 값으로 갱신했다. 버스 상세에 좌표도 표시되지만 단일 출처만으로 GPS 인증 좌표를 검증 완료로 만들지 않았고 CSV에는 옮기지 않았다.

공식 프로그램 페이지는 목록을 가나다순으로 제시할 뿐 1–100에 의미가 있는 공식 순번을 제공하지 않는다. CSV의 `order`는 기존 지역별 스테이징 순서를 보존한 내부 순서이며 BAC 공식 순위가 아니다. 이후 `collection_mountains.display_order`를 만들 때 이 사실을 마이그레이션 주석에 남겨야 한다.

## 산 정체성 잠금 규칙

| BAC 도전 대상 | 산림청 대응 | 판정 |
| --- | --- | --- |
| 감악산(파주) | 감악산 | 같은 산 정체성. 감악산(원주)와 합치지 않는다. |
| 감악산(원주) | 없음 | BAC 전용 별도 산. 원주/제천 정상석 대상이다. |
| 가야산(경상) | 가야산 | 합천·성주 권역의 같은 산 정체성이다. |
| 가야산(충남) | 없음 | 예산 권역의 BAC 전용 별도 산이다. |
| 오대산 비로봉 | 오대산 | 산림청 오대산과 같은 산 정체성이다. |
| 오대산 노인봉 | 없음 | BAC에서 별도 도전 대상으로 취급한다. 비로봉 인증지와 합치지 않는다. |
| 백운산(광양) | 백운산(광양) | 같은 산 정체성이다. |
| 백운산(동강) | 백운산(정선) | 같은 산 정체성이다. 백운산(포천)과 합치지 않는다. |
| 지리산 | 지리산 | 천왕봉을 요구하는 같은 산 정체성이다. |
| 지리산 바래봉 | 없음 | BAC 전용 별도 도전 대상이다. |
| 지리산 반야봉 | 없음 | BAC 전용 별도 도전 대상이다. |
| 지리산(통영) | BAC 대상 아님 | 사량도의 별도 산이며 지리산 본봉과 합치지 않는다. |
| 축령산(장성) | 없음 | 전남 장성의 BAC 전용 산이다. 산림청 축령산(경기)과 합치지 않는다. |
| 내변산(부안) | 변산 | 같은 산 정체성이고 BAC 인증지는 관음봉이다. |
| 도봉산 | 도봉산(자운봉) | 같은 산 정체성이지만 BAC 인증지는 신선대다. 산 이름과 인증지를 분리한다. |

추가로 `무등산`은 공식 BAC 응답에 `서석대 정상석/인왕봉 정상석` 두 지점이 함께 표기된다. 후속 인증지 모델링에서 하나의 문자열을 임의의 단일 좌표로 축약하지 말고, 실제 운영 규칙과 각 지점을 별도로 확인해야 한다.

## 저장소 반영 상태

- 2026-09-09에 산림청 공식 상세 페이지로 홍도 `깃대봉`의 정체성, 소재지(전남 신안군 흑산면 홍도), 현재 높이 표기(367.8m)를 다시 확인했다.
- `src/data/mountains.json`에는 표시용 높이를 반올림한 368m와 설명을 추가했지만, GPS 인증 좌표와 반경은 검증되지 않았으므로 `null`로 유지했다.
- 전체 산 정체성은 121개다. 두 컬렉션은 각각 100개이며 교집합 79개, 각 차집합 21개다.
- `0008_complete_collection_memberships.sql`과 생성된 `supabase/seed.sql`은 명시적 slug 매핑으로 산림청/BAC 멤버십을 만든다. 산림청에는 깃대봉을 포함하고 기존 데이터의 오서산 대체를 제외하며, BAC에는 오서산을 포함한다.
- 배포 시 서버 검증 블록이 산림청 100개, BAC 100개, 교집합 79개를 확인한다.
- `src/features/collections/index.ts`의 임시 이름 매칭은 아직 남아 있다. 우선순위 7에서 DB 멤버십 조회로 교체해야 한다.

이 반영은 컬렉션 기준 데이터만 수정하며 기존 인증 세션과 사용자 기록을 수정하지 않는다.
