# 100PEAKS — BAC 명산100 데이터 정책

## 제품 기준

100PEAKS의 100개 수집 대상은 BAC `명산100` challenge 대상 100개를 기준으로 정리한다.

단, 100PEAKS는 BLACKYAK/BAC와 제휴·공식 인증된 서비스가 아니다. 명산 목록 및 인증지 정보는 사용자 경험을 위한 데이터 기준으로 참고하며, 상표/브랜드 표현은 앱의 독립 서비스 정체성을 해치지 않도록 한다.

## 산과 인증 지점은 분리한다

`mountain`은 사용자가 수집하는 산/도전 대상이다.

`verification point`는 현장 인증에 실제로 사용하는 봉우리·정상석·지점이다.

예:

- 북한산 → 백운대
- 도봉산 → 신선대
- 계룡산 → 관음봉
- 금오산 → 현월봉
- 월악산 → 영봉
- 한라산 → 백록담

따라서 앞으로 데이터 모델은 산 이름과 인증 지점 이름을 같은 필드로 취급하지 않는다.

## GPS 안전 원칙

GPS 좌표는 추측해서 넣지 않는다.

`docs/data/bac100-candidates.csv`의 `coordinate_status=pending` 항목은 인증용 좌표로 사용하면 안 된다. 인증 기능에 연결하기 전 반드시 실제 인증 지점 기준 좌표를 신뢰할 수 있는 지도/공식·공공 데이터로 교차 확인한다.

인증 반경도 모든 산에 일괄적으로 임의 적용하지 않고 현장 환경과 GPS 오차를 고려해 검증한다. 좌표 검증이 끝나지 않은 산은 개발·운영 환경에서 GPS 인증을 활성화하지 않는다.

## 현재 교차검증 결과

사용자가 제공한 `100대명산.xlsx`(2022-01-01 기준 산림청 100대 명산)와 BAC challenge 후보 목록을 산/대표봉 표기 차이를 정규화하여 비교했다.

- 대응 가능한 대상: 79개
- BAC 목록에만 있는 대상: 21개
- 산림청 목록에만 있는 대상: 21개

BAC에만 있는 21개:

수락산, 청계산, 연인산, 감악산(원주/제천), 오대산 노인봉, 함백산, 청화산, 칠보산, 가야산(예산), 광덕산, 오서산, 용봉산, 구봉산, 지리산 바래봉, 지리산 반야봉, 달마산, 덕룡산, 동악산, 불갑산, 축령산(장성), 조령산.

산림청 목록에만 있는 21개:

강천산, 공작산, 금산, 깃대봉, 대암산, 덕숭산(수덕산), 명성산, 무학산, 미륵산, 백운산(포천), 서대산, 성인봉, 연화산, 운문산, 적상산, 점봉산, 지리산(사량도), 추월산, 축령산(경기), 황장산, 희양산.
